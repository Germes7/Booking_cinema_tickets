# Система бронирования билетов в кинотеатре

Учебный проект по разработке базы данных и реализации объектно-реляционного отображения (ORM) для управления кинотеатром.

## 📌 Основные сущности системы
* **Movies (Фильмы)** — информация о кинокартинах и их длительности.
* **Hall (Залы)** — кинозалы с указанием их вместимости.
* **Seat (Места)** — физические кресла, привязанные к конкретным залам.
* **Viewer (Зрители)** — база данных зарегистрированных клиентов.
* **Session (Сеансы)** — расписание показов фильмов в залах с привязкой ко времени.
* **Ticket (Билеты)** — факт покупки/бронирования места зрителем на определенный сеанс.

## 📊 ER-диаграмма базы данных
Схема структуры таблиц и связей между ними (Foreign Keys) спроектирована в СУБД SQLite через DBeaver. 
Ознакомиться со схемой можно в папке `Diagrams`.

## 🛠 Технологический стек
* **Язык программирования:** Python 3
* **СУБД:** SQLite
* **Инструменты проектирования:** DBeaver
* **Среда разработки:** PyCharm
